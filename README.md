🎬 App de Filmes (MoviesFlix)
Uma aplicação web dinâmica e responsiva construída com React para explorar o catálogo mundial de cinema. O projeto consome a API do TMDB (The Movie Database) para exibir dados e imagens atualizadas sobre filmes, tendências e lançamentos.

✨ Funcionalidades
Catálogo Atualizado: Listagem de filmes em alta, lançamentos e navegação por categorias em tempo real.

Navegação SPA (Single Page Application): Transições fluidas entre a página inicial e os detalhes de cada filme sem recarregar a página.

Gerenciamento de Estado: Uso avançado de React Hooks (useState, useEffect) para controle eficiente de ciclo de vida e renderização de dados.

🚀 Tecnologias Utilizadas
React: Biblioteca principal para a construção da interface de usuário baseada em componentes.

Vite: Ferramenta de build configurada para oferecer um ambiente de desenvolvimento extremamente rápido, com Hot Module Replacement (HMR) otimizado.

React Router DOM: Biblioteca responsável pelo gerenciamento de rotas e navegação da aplicação.

TMDB API: Integração com a API RESTful para consumo de endpoints de filmes.

🛠️ Como executar o projeto localmente
Pré-requisitos
Certifique-se de ter o Node.js e o npm (ou Yarn) instalados na sua máquina. Você também precisará criar uma conta no TMDB para gerar uma chave de API (API Key) gratuita.
